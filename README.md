# Lichess Badges

[Shields.io](https://www.shields.io) generated badges for [Lichess.org](https://www.lichess.org).

## Examples

[![Lichess Blitz](https://lichess-badges.vercel.app/api/rating/DrNykterstein/blitz)](https://lichess.org/@/DrNykterstein)

## Endpoints

- [OpenAPI Documentation](https://lichess-badges.vercel.app/docs)

## Deploy

```bash
docker build -t lichess-badges && docker run -it --rm -p 80:80 lichess-badges
```

View OpenAPI docs at `http://localhost/docs`.
